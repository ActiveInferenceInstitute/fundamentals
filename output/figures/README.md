## Figure registry

`figure_registry.json` is the one **tracked** file here. It is not generated: it
records, for every figure the manuscript cites, the label, the path relative to
this directory, the producing orchestrator, the caption, and the alternative
text. `scripts/render_manuscript.py` binds the registry caption and alternative
to the rendered figure and fails when a registered file is missing, a manuscript
figure is unregistered, or a registry entry goes unused. Validate with
`./gate.sh manuscript-check`.

## Regenerate

```bash
# remove generated media and re-render everything; README files are preserved
python scripts/run_all_figures.py --clean

# only one chapter
./scripts/run_all_chapter_03.sh

# skip GIFs for a faster pass
python scripts/run_all_figures.py --no-animations

# check rendered artifacts for corrupt, blank, or undersized output
python scripts/validate_rendered_figures.py --root output/figures

# check extras registry declarations against rendered PNG/GIF and NPZ+JSON artifacts
python scripts/validate_book_topic_coverage.py --require-rendered

# check the inspected PDF ledger: Ch.1-14, Appendices A-D, no Ch.15
python scripts/validate_source_spine.py --require-pdf

# render all extras through the shared menu runner
python -m active_inference.menu --extras

# render all extras through the batch renderer
python scripts/run_all_figures.py --no-chapters --extras
```

## Recorded manifest

The counts in the table above describe **one default render** of each chapter.
They are checked against the chapter's own `README.md` — the recorded manifest —
and never against the files on disk:

- Each `chapter_NN/README.md` lists its default artifacts under
  `## Expected files` and, where a flag changes the output filename, the
  alternative under `## Flag variants`.
- `tests/test_documentation_contracts.py` requires the two documents to agree
  on the default counts, and requires any media that *is* present to be
  recorded in one of those two sections.

A partial, interrupted, or flag-variant render is therefore a supported state
and never a documentation failure: `output/figures/` is regenerable and most
checkouts hold little or none of it. `python
scripts/validate_rendered_figures.py --root output/figures` checks whatever is
present for corrupt, blank, or undersized output.

## Conventions

- Filenames mirror the orchestrator that produced them.
- Default DPI is 150 for PNGs and 110 for GIF frames.
- Animations use the bundled pillow GIF writer — no FFmpeg or
  ImageMagick installation required.
- `.gitignore` excludes new PNG / GIF media here so generated artifacts do
  not pollute Git history; README files document what each chapter should
  regenerate.
